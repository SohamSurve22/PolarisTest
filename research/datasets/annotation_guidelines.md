# Annotation Guidelines

## Goal
Create gold labels independently of the PolarisLex system's predictions.

## Status Definitions
- **covered**: All material requirement elements are satisfied with adequate evidence
- **partial**: Some but not all requirement elements satisfied
- **missing**: No adequate evidence for required elements
- **violation**: Policy actively violates the obligation (e.g., contradicts legal requirement)
- **conflict**: Contradictory statements within policy
- **undetermined**: Cannot determine from available evidence
- **not_applicable**: Obligation not applicable to this policy/entity type

## Rules
1. An obligation is NOT fully covered just because one element is satisfied
2. Denials/exclusions count against coverage if they negate required disclosures
3. Third-party statements don't establish publisher's practices
4. Generic boilerplate doesn't satisfy specific requirements
5. Cross-references must be resolvable or don't count
6. Ambiguous cases marked as undetermined, not guessed
7. Record rationale for each label

## Adjudication
- Single annotator for pilot, record disagreements if multiple annotators
- Document uncertainty
- Flag cases needing legal review

## Provenance
Record source document, URL (if available), retrieval date for each case
